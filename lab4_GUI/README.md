# Shopping Mall Model

Программная система, моделирующая работу торгового центра. Разработана на чистом Python с соблюдением принципов ООП (SOLID, DRY, KISS).

## Структура проекта
Проект разделен на логические слои для обеспечения масштабируемости:
- `domain/` - Содержит бизнес-сущности (`models.py`) и пользовательские исключения (`exceptions.py`).
- `services/` - Содержит бизнес-логику и фасад для операций (`operations.py`).
- `cli/` - Интерфейс командной строки (`interface.py`).
- `tests/` - Unit-тесты для проверки работы бизнес-правил (`test_models.py`).
- `main.py` - Точка входа, собирающая зависимости и запускающая приложение.

## Основные сущности
- **ShoppingMall** (Торговый центр) и **ShoppingGallery** (Торговая галерея)
- **Shop** (Магазин), **Seller** (Продавец) и **CashRegister** (Касса)
- **Buyer** (Покупатель) и **Product** (Товар)
- **Promotion** (Акции и скидки)

## Требования
- Python 3.8 или выше.
- Сторонние библиотеки не требуются (используется стандартная библиотека Python).
