# Шашки (Checkers) — Python & Pygame

Игра в шашки, написанная на Python с использованием библиотеки Pygame. 

Проект спроектирован с использованием строгой архитектуры MVC.

## Особенности проекта

* **Игровые режимы:**
  * **Игра с собой:** 
  * **Игра на двоих:** доска автоматически переворачивается после каждого хода.
* **Полноценный UI/UX:**
  * Главное стартовое меню.
  * Панель интерфейса.
  * Внутриигровое меню паузы и экран окончания игры
  * Звуковое сопровождение.
