# Система управления торговым центром (Shopping Mall Management System)

Данный проект представляет собой программную систему для управления сетью торговых центров. 
Приложение позволяет моделировать работу торговых галерей, магазинов, продавцов и покупателей, 
а также осуществлять покупку товаров.

Разработано с использованием паттерна MVP и поддерживает два режима работы: графический и консольный.

## Функциональные возможности

* **Управление торговыми центрами:** Создание новых ТЦ, просмотр списка, удаление.
* **Управление магазинами:** Аренда мест в торговой галерее, удаление магазинов.
* **Управление инвентарем:** Добавление и удаление товаров.
* **Операции покупателя:** Покупка товаров, просмотр истории купленных товаров.


* **Система акций:** Возможность участия покупателя в программе лояльности для получения скидок.
* **Оценка сервиса:** Возможность выставления рейтинга (1.0 - 5.0) продавцам после посещения магазина.
* **Автосохранение данных:** Все действия (покупки, изменение баланса, редактирование каталога) мгновенно и автоматически сохраняются в базу данных формата JSON.

## Архитектура проекта

Проект спроектирован с соблюдением принципов чистого кода (SOLID) и архитектурного паттерна **Model-View-Presenter (MVP)**:

* **Model (`src/models.py`, `src/services.py`):** Содержит классы предметной области (доменные сущности) и чистую бизнес-логику. Данный слой не имеет никаких зависимостей от пользовательского интерфейса.
* **View (`src/views/gui_view.py`, `src/views/cli_view.py`):** Пассивные представления. Отрисовывают данные и собирают пользовательский ввод, передавая его в Презентер.
* **Presenter (`src/presenter.py`):** Связующее звено. Обрабатывает события от представлений, вызывает методы сервисов и дает команды представлениям на обновление экрана.

## Требования и установка

Для работы приложения требуется Python 3.8 или выше.
Графический интерфейс реализован на базе библиотеки PySide6 (официальный биндинг Qt для Python).

Установка зависимостей:

```
pip install PySide6
```

## Запуск приложения

Точкой входа в приложение является файл `main.py`. Выбор интерфейса осуществляется через аргумент командной строки `--mode`.

### Графический интерфейс (GUI)

Запускается по умолчанию или при явном указании флага:

```
python main.py --mode gui
```

**Особенности GUI:**

* Поддерживает два вида отображения: Древовидный (для разработчика) и Страничный (для клиента). Переключение доступно в меню "Вид".
* Все операции по управлению объектами (создание/удаление) находятся в верхнем системном меню "Управление".

### Консольный интерфейс (CLI)

Запускается при указании флага:

```
python main.py --mode cli
```

**Особенности CLI:**

* Представляет собой иерархическую навигацию по системе.
* Переход по уровням осуществляется вводом номера объекта.
* Действия привязаны к символам в порядке qwerty.

## Хранение данных

Система использует файл `mall_data.json` в корневой директории для хранения состояния.
